# Pemulasaraan Jenazah: Integrasi Kedokteran dan Keislaman

Materi ajar untuk mahasiswa S1 Pendidikan Dokter, mata kuliah Integrasi Keilmuan.

## Isi repositori

| File | Keterangan |
|---|---|
| [`materi.md`](materi.md) | Materi lengkap: tahapan pengurusan jenazah, perbedaan rujukan, integrasi medis, kasus diskusi |
| [`soal.md`](soal.md) | 20 soal pilihan ganda, 5 soal kasus, 3 topik diskusi (kunci jawaban dipegang pengajar) |

## Sumber utama

1. Yayasan Raudhatul Jannah Semarang, *Pedoman Pengurusan Jenazah Muslim*
2. Majelis Tarjih dan Tajdid PWM DIY, *Tuntunan Perawatan Jenazah*
3. Kemenag RI, Tanya Jawab Fiqih tentang pedoman pemulasaraan jenazah

Daftar rujukan lengkap ada di bagian akhir `materi.md`.

## Catatan

- Materi merangkum rujukan di atas dan menandai perbedaan penekanannya.
- Bagian integrasi medis adalah ringkasan umum untuk bahan diskusi, bukan pedoman klinis.
- Untuk kasus khusus (jenazah berisiko infeksi, autopsi, donor organ), rujuk fatwa lembaga resmi dan pedoman Kemenkes yang berlaku.
